# `data/` — Balkans Civilian Geographic Atlas

Everything the atlas is built from and everything it builds. All of it is regenerated by
`python3 scripts/run_pipeline.py` (or `--offline` to rebuild from `raw/` without downloading). Only files under the
approved civilian workspace are read (source-isolation allowlist, `config/` + `ogr_utils.assert_isolated`);
nothing from earlier "Balkans Atlas" releases is used.

Coverage: Albania, Bosnia and Herzegovina, Bulgaria, Croatia, Greece, Kosovo\*, Montenegro, North Macedonia,
Romania, Serbia, Slovenia and European Türkiye (ISO3 codes ALB BIH BGR HRV GRC XKX MNE MKD ROU SRB SVN TUR).
All vector layers are EPSG:4326; areas are computed in EPSG:3035.

## Folder layout

| Folder | Size | What it holds | Rebuilt by |
|---|---|---|---|
| `raw/` | 3.4 GB | Downloads, unchanged, exactly as the source served them. Every file has a SHA-256, URL, licence and retrieval time in `provenance/provenance.csv`. | `scripts/import/fetch_*.py` |
| `reference/` | 1.7 MB | Hand-compiled, cited tables (see below). Edit these by hand; each row carries its source. | — |
| `processed/` | 1.7 GB | `balkans_civilian_atlas.gpkg` (all vector layers) and `terrain/` (DEM, hillshade, slope rasters). | `scripts/processing/*.py` |
| `hazards/` | 197 MB | Hazard rasters clipped to the atlas window + `HAZARD_LAYERS.csv` (metadata). | `build_hazards.py` |

## What is deliberately not in this folder

- Military installations, training areas or bases; military-tagged helipads and towers are filtered out.
- Checkpoints, patrols, surveillance cameras, radar or observation towers.
- Routes, waypoints or tracks of any kind other than published hiking, ferry and rail lines.
- Anything from the legacy "Balkans Atlas" V10–V12 folders.

These exclusions are enforced in the classifiers (`scripts/processing/build_osm_layers.py`) and by the
source-isolation check, not just by convention.

## Rules for adding data

1. Put the download in a new `raw/<source>/` folder through a `scripts/import/fetch_*.py` script that calls
   `register_provenance` (hash, URL, licence, date).
2. Build the layer in `scripts/processing/`, writing the provenance fields above on every feature.
3. Register the layer in `src/balkans_atlas/provenance/engine.py` and `config/layers.yaml`, then run
   `python -m balkans_atlas provenance check` and `layers validate` (both must report 0 problems).
4. Unverified sources stay marked unverified. Never estimate or fill missing values.

\*This designation is without prejudice to positions on status, and is in line with UNSCR 1244/1999 and the ICJ
Opinion on the Kosovo declaration of independence.
